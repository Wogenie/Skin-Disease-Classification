# Skin Disease Classification

An AI-powered skin disease classification system built using Deep Learning, TensorFlow, FastAPI, and computer vision techniques. This project is designed to classify skin diseases from uploaded skin images and provide fast predictions through a web-based interface.

---

# Project Overview

Skin diseases are among the most common medical conditions worldwide. Early detection and diagnosis can significantly improve treatment outcomes. This project aims to assist in preliminary skin disease analysis by using a Convolutional Neural Network (CNN) model trained on skin image datasets.

The system allows users to:

* Upload a skin image
* Process and classify the disease
* Receive prediction results instantly
* Interact through an API-based backend

This project combines:

* Deep Learning
* Computer Vision
* TensorFlow/Keras
* FastAPI
* Python

# Model Workflow

The complete pipeline works as follows:

1. User uploads a skin image
2. Image preprocessing is applied
3. The image is resized and normalized
4. TensorFlow model performs prediction
5. Predicted disease class is returned
6. Results are displayed through API or frontend

---

# Image Preprocessing

The system applies multiple preprocessing steps before prediction:

* Image resizing
* RGB conversion
* Normalization
* Tensor conversion
* Batch dimension expansion

These steps improve model consistency and prediction quality.

---

# API Backend

The backend is built using FastAPI for high-speed inference and easy deployment.

## Example Endpoint

```python

```

The API accepts uploaded images and returns prediction results in JSON format.

# Installation Guide

## 1. Clone Repository

```bash
git clone https://github.com/Wogenie/Skin-Disease-Classification.git
```

## 2. Navigate Into Project

```bash
cd "Skin Disease Detection"
```

## 3. Create Virtual Environment

```bash
python -m venv ml_venv
```

## 4. Activate Virtual Environment

### Windows

```bash
ml_venv\Scripts\activate
```

### Linux/Mac

```bash
source ml_venv/bin/activate
```

## 5. Install Dependencies

```bash
pip install -r requirements.txt
```
